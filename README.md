#📝 Convertir Word a HTML (negritas e italicas)
Creado 14/oct/2025

Script que covierte los words a texto html con etiquetas

---

- Convierte negritas de word a '<strong>'.
- Convierte italicas de word a '<i>'.
- Usa la libreria mammoth.
- Elimina todas las demas etiquetas.
- Muestra el contenido en front con saltos de linea.
- No requiere conexion a internet ni instalacion de dependencias.
